# AMPTemplate

Eigene Templates für [CubeCoders AMP](https://cubecoders.com/AMP), bereitgestellt und gepflegt von **Fabius-Haselnuss**.

## Was enthält dieses Repository?

Aktuell enthält das Repository ein AMP-Template für **Life is Feudal: Your Own**. Damit lässt sich der Dedicated Server über AMP verwalten. Das Template umfasst:

- Installation und Updates der Windows-Dedicated-Server-Dateien über SteamCMD
- Einstellungen für den Spielserver in der AMP-Oberfläche
- Konfiguration der Datenbankverbindung über `config_local.cs`
- Konfiguration der Spielwelt über `config/world_1.xml`
- Definition der benötigten Serverports

Die AMP-Template-Dateien liegen im Hauptverzeichnis, damit AMP sie direkt abrufen kann.
